# Неопалимая Купина — сайт паломнической службы (демо)

Демонстрационный визуальный прототип сайта паломнической службы «Неопалимая Купина». Собран на Vite + React +
TypeScript, без бэкенда: все формы имитируют отправку, данные никуда не уходят.

> **Это прототип.** Даты поездок, цены, количество свободных мест, фотографии, отзывы, биография сопровождающего и
> реквизиты организации — демонстрационные и требуют подтверждения перед публикацией. Полный список того, что нужно
> получить от владельцев службы, — в [CONTENT_NEEDED.md](./CONTENT_NEEDED.md).

## Стек

- [Vite](https://vite.dev/) + [React 19](https://react.dev/) + TypeScript
- [react-router-dom](https://reactrouter.com/) для маршрутизации (главная страница, страница поездки, 404)
- Обычный CSS (переменные + БЭМ-подобные имена классов), без CSS-фреймворков
- [oxlint](https://oxc.rs/) для линтинга
- Шрифты Google Fonts: PT Serif (заголовки) и PT Sans (интерфейс) — выбраны как пара, специально поддерживающая
  кириллицу

Внешние npm-зависимости сайта сведены к минимуму: `react`, `react-dom`, `react-router-dom`.

## Структура проекта

```
src/
  components/     переиспользуемые UI-блоки (шапка, карточка поездки, модалки, аккордеон и т.д.)
  context/        React-контексты: модальные окна и тосты-уведомления
  data/
    trips.ts      данные о поездках — единственный источник правды для карточек и страницы поездки
    content.ts    данные для остальных секций (преимущества, отзывы, FAQ, галерея, шаги процесса)
    constants.ts  телефон, точки посадки, тексты демо-уведомлений
  hooks/          useDocumentMeta — управление <title> и meta description на каждой странице
  pages/          HomePage, TripDetailPage, NotFoundPage
  utils/          форматирование цены и русских склонений
preview/          скриншоты главной страницы и страницы поездки (desktop и mobile)
```

Часть фотографий на сайте (главный экран, пять из семи карточек поездок, галерея, блок «О службе», блок
социальной миссии и портрет сопровождающего) — реальные снимки, отобранные и сжатые копии лежат в `public/photos`
(исходный архив поездок — в `photos/` рядом с проектом, в репозиторий не попадает, см. `.gitignore`). Там, где
подходящего фото не нашлось (две поездки без фото в архиве), остаются стилизованные CSS/SVG-
заглушки (компонент `PlaceholderPhoto`) с подписью «демо-фото». Перед публикацией нужно подтвердить права на
использование архивных фото и заменить оставшиеся заглушки на реальные снимки — см. CONTENT_NEEDED.md.

## Команды

```bash
npm install       # установка зависимостей
npm run dev       # локальная разработка (http://localhost:5173)
npm run lint      # проверка кода (oxlint)
npm run build     # проверка типов (tsc) + продакшн-сборка в dist/
npm run preview   # локальный просмотр собранной версии
```

## Демонстрационное поведение

- Форма бронирования (карточка поездки → «Забронировать», страница поездки → «Забронировать место») не отправляет и
  не сохраняет данные. После нажатия «Отправить заявку» показывается сообщение о том, что это демоверсия, и номер
  телефона для реальной записи.
- Кнопки Telegram и WhatsApp в финальном блоке показывают уведомление о том, что ссылка появится после согласования
  с владельцами службы — реальные мессенджер-контакты не подтверждены.
- Кнопка в блоке социальной миссии открывает информационное модальное окно — реального сбора средств на сайте нет.
- «Задать вопрос» открывает модальное окно с номером телефона — форма ничего не отправляет.

## Доступность и техническая часть

- Mobile-first вёрстка, корректно работает от ширины 360 px.
- Семантическая разметка (`header`, `nav`, `main`, `footer`, `dl`, `details/summary` для FAQ).
- Клавиатурная навигация: фокус-стили, доступные модальные окна (Escape закрывает, Tab не выходит за пределы окна,
  фокус возвращается на элемент, который открыл окно).
- Поддержка `prefers-reduced-motion` — анимации и плавный скролл отключаются по системной настройке.
- Отдельная страница 404 для несуществующих маршрутов и несуществующих поездок.
